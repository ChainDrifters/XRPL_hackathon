## Scope

The split architecture covers:

- XRPL DID as the public trust anchor for issuers
- Private holder identity graphs and pairwise relationship IDs
- W3C Verifiable Credentials and optional coarse XRPL Credentials
- Privacy boundaries between user wallet, XRPL, issuers, verifiers, and regulated off-chain storage
- Credential status, revocation, holder consent, access grants, and audit logs
- Tax refund, hotel, rental, license verification, and escrow event linkage

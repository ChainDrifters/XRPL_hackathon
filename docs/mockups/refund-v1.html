환급 페이지 디자인 의도 — Progressive Disclosure 전략

핵심 원칙: 일반 외국인 사용자(95%)는 Screen 1→2→3 한 흐름으로 KRW 환급을 받고 web3를 전혀 마주치지 않습니다. RLUSD/주소/QR이 필요한 advanced 사용자(5%)는 Screen 3에서 "출국 후에도 받기" 옵션을 선택하면 Screen 4(보관함)→5(외부 출금)로 자연스럽게 진입합니다. Web3 요소는 없는 게 아니라, 필요한 사람만 보입니다.

CASUALScreen 1 — 환급 탭 홈
상단 큰 카드 = 받을 수 있는 합계. "진행 중 / 받을 수 있어요 / 완료" 3-tier 분류. 모든 표시는 원 단위. RLUSD 단어 0회. 진행률은 5-segment progress bar (E0~E7을 사용자 친화 5단계로 매핑).
CASUALScreen 2 — 환급 상세
단일 case의 timeline 확대. 각 step에 친근한 한국어 설명 + 정확한 시각. 기술 용어(card_authorization_verified, customs_export_confirmed) 모두 한국어 카피로 번역. 상단 우측 🔗 = 영수증/proof 보기 (judges용 demo panel은 여기서 진입).
CASUALScreen 3 — 받는 방법 선택
4가지 옵션: 카드 / 은행 / 출국 후 받기 (RLUSD custody) / 공항 현금. 기본 선택 = "한국 카드로" (가장 친숙). RLUSD 옵션은 "출국 후에도 받기 · 빠름"으로 framing — 단어 RLUSD 안 나옴. 비기술 사용자는 default 선택만으로 끝. Advanced 진입은 자기 의지.
WEB3-LITEScreen 4 — 환급 보관함
여기서 처음으로 RLUSD 단어 등장 (≈ 215.42 RLUSD를 KRW 옆에 작게 표시). 하지만 강조는 295,700원. "토스가 안전하게 보관" 메시지로 custody 모델 설명. 하단 "고급" 섹션에 받는 주소/외부 출금/tx 내역 진입점 — power user만 발견.
WEB3-FULLScreen 5 — 외부 지갑 출금
모든 web3 필수 요소 등장: XRPL 주소 (rXXX...), QR 코드, Destination Tag, 네트워크 수수료 (0.00001 XRP), 받는 사람 주소 검증 ("Coinbase 입금 주소로 확인됐어요"), 24h cooldown alert, RLUSD ↔ KRW 환산 표시.

• 처음 보내는 주소 = 24h cooldown + 취소 가능 (이전 분석의 Oracle 권고)

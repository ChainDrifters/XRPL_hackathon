홈 화면 설계 의도

1여권 인증 + 환급 금액 (Hero)
가장 위에 두 가지를 함께 강조 — 사용자가 "내 신원이 준비되어 있고", "받을 돈이 얼마인지" 한 번에 인식. "여권 확인을 마쳤어요" = identity wallet ready 신호를 비전공자도 이해 가능한 카피로.
2출국까지 D-day 표시
외국인 사용자의 가장 큰 stress는 "공항에서 시간 안에 환급 받기". 메인 hero에 "출국까지 N일" 명시 → 행동 유도.
33개 quick action
"키오스크에 보여주기" / "전표 추가" / "받을 방법 설정" — 면세 환급의 3대 사용자 액션. "지갑", "주소", "서명" 같은 web3 용어 0.
4출국 alert (노란색 카드)
반드시 해야 할 일을 강조 — 세관 키오스크 안 거치면 환급 취소되는 한국 제도의 핵심 위험 포인트.
5진행 중 환급 timeline
E0~E7 proof chain을 사용자 친화적으로 시각화 — "구매 → 면세 확인 → 키오스크 → 세관 → 환급 완료". 현재 단계 강조 + 다음 액션 명확.
6최근 구매 + 환급액 미리보기
매장별 환급 가능 금액 즉시 표시 → "내가 얼마 받을 수 있는지" 투명성. 즉시환급 vs 사후환급 구분.
7미래 확장 preview
"같은 인증으로 호텔/렌탈도" — DID 재사용 가치 어필. 토스 시너지 + 제품 vision 동시 표현.
8Bottom navigation 4탭
홈 / 환급 / 활동 / 설정 — 토스 standard. 환급 탭에서 detail, 활동 탭에서 audit log, 설정에 "받을 방법" + "고급" (BIP-39 export 등).
9Web3 용어 완전 hide
XRPL, RLUSD, DID, VC, wallet, signing 모두 사용자 화면에서 안 보임. 설정 > 고급 > 개발자에만 노출.

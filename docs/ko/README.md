## 권장 읽기 순서

1. [프로젝트 계획서](plan.ko.md)에서 문제 정의, MVP 범위, 법적 경계, 발표용 문구를 확인합니다.
2. [체인 아키텍처 개요](architecture/overview.ko.md)에서 온체인/오프체인 분리를 확인합니다.
3. 지갑 또는 Verifier를 구현하기 전에 [식별자 모델](architecture/identifiers.ko.md)을 읽습니다.
4. DID, VC, Status List, XRPL Credential을 구현하기 전에 [자격증명 모델](architecture/credentials.ko.md)을 읽습니다.
5. 서비스 이벤트나 증거 데이터 접근을 다루기 전에 [기록 및 접근 제어](architecture/records-access.ko.md)를 읽습니다.
6. CDD 원본 보관을 구현하기 전에 [암호화 아키텍처](security/encryption-architecture.ko.md)를 읽습니다.
